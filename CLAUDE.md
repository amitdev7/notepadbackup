# Zenithsui Project Guidelines & Constraints ,Important Rule MUST Follow

## CRITICAL: Strict UI/UX, Design, Look & Feel Preservation Directive
- **ABSOLUTE INVARIANT: NEVER CHANGE THE LOOK, UI, UX, DESIGN, OR THEME**: Under NO circumstances should you alter, redesign, restyle, refactor, or modernize the existing look, UI, UX, design system, theme, typography, color scheme, spatial layout, borders, buttons, or aesthetic of the Zenithsui application.
- **Napkin/Rough Sketch Aesthetic**: The signature hand-drawn rough.js napkin wireframe aesthetic is the core identity of the product and MUST remain completely unchanged.
- **Preserve All Existing UI Elements**: Keep all toolbars, icons, palettes, canvas behaviors, menus, rails, modal dialogs, and panels exactly in their established positions, sizing, and styling.
- **Design Continuity for New Features**: Any new features, modals, or components MUST seamlessly match the existing Zenithsui visual tokens, CSS variables, and interaction patterns.
- **Zero Unsolicited Redesigns**: Do NOT introduce new color palettes, rounded modern cards, gradient backgrounds, or alternative layout paradigms.
