# Zenithsui Brand Assets & Guidelines

This directory contains the official visual identity, branding assets, social preview graphics, and application screenshots for **Zenithsui**.

---

## Directory Organization

```
assets/branding/
├── logo/
│   ├── zenithsui-logo.svg           # Scalable vector brand mark
│   ├── zenithsui-icon-512x512.png   # High-resolution raster icon
│   └── zenithsui-icon-180x180.png   # Apple touch & web app icon
├── social-preview/
│   ├── zenithsui-social-preview.svg # 1280×640 vector Open Graph banner
│   └── zenithsui-social-preview.png # 1280×640 raster social preview
└── screenshots/
    ├── hero-overview.jpg            # Main infinite canvas wireframing workspace
    ├── canvas-desktop-workspace.png # Full desktop workspace with toolbars
    ├── canvas-tablet-workspace.png  # Tablet viewport layout
    ├── canvas-mobile-workspace.png  # Mobile responsive layout
    ├── dashboard-file-manager.png   # Multi-document workspace & files manager
    ├── shadcn-component-library.png # shadcn/ui sketch component drawer
    ├── inspector-property-panel.png # Property inspector & variant switcher
    ├── settings-preferences-dialog.png # System settings & theme configurator
    └── command-palette-spotlight.png   # ⌘K Command palette & quick actions
```

## Brand Colors

| Token | Hex | Role | Usage |
|---|---|---|---|
| `--ui-accent` | `#007AFF` | Primary Accent | Active states, selection bounds, CTA buttons |
| `--background-light` | `#FAF9F5` | Paper Light | Parchment canvas background |
| `--background-dark` | `#0D1117` | Canvas Dark | Midnight OLED canvas background |
| `--ink-blue` | `#2563EB` | Sketch Blue Ink | Rough.js hand-drawn wireframe strokes |
| `--glass-pill` | `rgba(255,255,255,0.08)` | VisionOS Glass | Top bar capsule & bottom dock backdrops |

## How to Configure the GitHub Social Preview

To upload the social preview to the GitHub repository:

1. Navigate to the repository homepage: `https://github.com/amitdev7/notepadbackup`.
2. Click **Settings** (top navigation bar).
3. Under the **General** tab, scroll down to the **Social preview** section.
4. Click **Edit** -> **Upload an image…**.
5. Select `assets/branding/social-preview/zenithsui-social-preview.png`.
6. Click **Save changes**.
